# Finance Tracker

https://lukecutmore.github.io/finance-tracker/?utm_source=chatgpt.com

## About the Project
 Finance Tracker is a simple web application I built as my second main personal coding project.

It allows users to record their income and expenses, track their transactions and see an overview of their finances.

I built this project to strengthen my understanding of JavaScript, DOM manipulation and CSS, while getting more comfortable building an application from scratch.

## Features
Add income and expense transactions with a description and amount.

Automatically calculate and display total balance, income and expenses.

Delete individual transactions and update the totals accordingly.

Save transaction history using localStorage, so data is retained when the page is refreshed.

Validate user inputs to prevent empty descriptions and invalid amounts.

Display transaction amounts in GBP (£) with two decimal places.

Colour-code income and expenses for easier identification.

Responsive layout for desktop and mobile screens.

## Technologies Used
HTML5 – Structure and layout of the application.

CSS3 – Styling, Flexbox and responsive design.

JavaScript – Application logic, DOM manipulation, event handling and calculations.

localStorage – Saving and retrieving transaction data in the browser.

## How to Run
Download or clone this repository.

Open the project folder.

Open index.html in a web browser.

No additional installations or dependencies are required.

## How to Use

Enter a transaction description and amount.

Select whether the transaction is income or an expense.

Click Add Transaction.

View your updated balance, income and expenses on the dashboard.

Use the Delete button to remove transactions.
